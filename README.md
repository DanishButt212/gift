# Tumhare liye 🌹

Ek chhota sa gift — 3 options: **Ek Gulab**, **Phoolon ka Bagh**, aur **Guldasta aur Khat**.

## Kaise kholein

`Gift.html` ko browser mein kholein. GitHub Pages par yehi file chalti hai:
`https://danishbutt212.github.io/gift/Gift.html`

Pehle screen par tap karte hi gaana shuru ho jata hai.

## Gaana — Alvida Alvida 🎵

- **Song:** Alvida Alvida (From "Dar-e-Nijaat")
- **Singers:** Nabeel Shaukat Ali & Osaf Fateh Ali Khan
- **Composer:** Naveed Nashad · **Lyrics:** Qamar Nashad · ℗ 2026 ARY Digital

Gaana option/menu page aate hi shuru hota hai, **loop par chalta hai (poora song, phir dobara)**,
aur koi bhi option choose karne ya **Wapas** aane par nahi rukta — player main page par hai,
option wale pages ke andar nahi.

Gaana repo mein hi hai: `alvida.mp4` (13 MB, 640x360, poora official ARY Digital
video — https://www.youtube.com/watch?v=cX5YhkapzVk). Page ka `<audio>` element
usi ko loop par chalata hai. Agar `alvida.mp4` na chale to official YouTube
embed fallback ke tor par chal jata hai.

Note: gaana ARY Digital ka copyrighted OST hai — public repo mein rakhne par
DMCA takedown ka risk rehta hai.
